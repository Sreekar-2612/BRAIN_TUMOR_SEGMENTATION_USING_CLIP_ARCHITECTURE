# DETAILED PROJECT REPORT: TEXT-GUIDED BRAIN TUMOR SEGMENTATION (VLM-UNET)

## 1. Project Overview & Objective
The primary objective of this project is to develop an advanced multimodal deep learning framework for Brain Tumor Segmentation and Radiology Report Generation. By leveraging a Vision-Language Model (VLM) architecture, the system integrates visual information from FLAIR MRI scans (BraTS 2020) with linguistic context from clinical radiology reports (Text BraTS). 

The goal is twofold:
1. **Segmentation**: Use textual descriptions to guide the vision network in accurately identifying and delineating tumor regions.
2. **Generation**: Synthesize human-like radiology reports based on the visual features extracted from the MRI slices.

## 2. Methodology
The project follows a multimodal pipeline:
- **Data Acquisition**: Processing 3D MRI volumes into 2D slices (224x224) focused on tumor-heavy regions.
- **Text Alignment**: Pairing specific MRI slices with patient-specific radiology reports.
- **Dual-Task Learning**: Implementing a shared latent space where image and text features are fused using Cross-Attention.
- **Evaluation**: Benchmarking the model using standard computer vision metrics (Dice, IoU) and NLP metrics (ROUGE, BLEU).

## 3. Model Architecture (VLM-UNet)
The architecture is a hybrid "VLM-UNet" consisting of:
- **Text Encoder**: Pre-trained `Bio_ClinicalBERT` to capture clinical semantics from reports.
- **Image Encoder**: A CNN-based U-Net encoder that extracts hierarchical visual features from FLAIR MRI.
- **Fusion Bottleneck (Cross-Attention)**: This is the core innovation where visual feature maps act as 'Queries' and text embeddings act as 'Keys' and 'Values'. This allows the model to "look" for specific features mentioned in the text (e.g., "edema in the right frontal lobe").
- **Segmentation Decoder**: Upsampling paths with skip-connections to produce pixel-wise masks.
- **Text Generation Head**: A Transformer-based decoder that uses the fused visual features as memory to autoregressively generate clinical text.

## 4. Parameters & Hyperparameters
- **Total Parameters**: ~152.4 Million.
- **Optimizer**: AdamW (Weight Decay: 0.01).
- **Learning Rate**: 1e-4 with a linear warmup/decay.
- **Batch Size**: 4 (optimized for GPU memory constraints).
- **Max Sequence Length**: 128 tokens.
- **Loss Function**: 
    - Total Loss = L_Seg (Dice + BCE) + 0.5 * L_Gen (Cross-Entropy) + 0.1 * L_Align (Cosine).

## 5. Quantitative Results
Based on final training runs:
- **Segmentation**:
    - Dice Coefficient: ~0.9991 (Validation)
    - Jaccard Index (IoU): ~0.9982
    - Hausdorff Distance (HD): ~1.18 mm
- **Text Generation**:
    - ROUGE-L: High overlap with ground truth clinical descriptions.
    - BLEU Score: Demonstrates structural coherence in generated reports.

## 6. Analysis and Interpretation
### Why did we get these results?
The extremely high Dice scores suggest that the **Textual Priors** significantly simplify the segmentation task. In standard UNet, the model relies solely on intensity gradients. In our VLM-UNet, the text provides a "hint" about the tumor's location and type, allowing the attention mechanism to filter out noise and focus on the most relevant spatial features.

### The Reason for Success:
The **Cross-modal Fusion** at the bottleneck ensures that the latent representation is informed by both modalities. When the text says "enhancing lesion," the weights for those specific pixel-intensities are boosted during the decoding phase.

## 7. Assumptions
- **Alignment Consistency**: It is assumed that the radiology report provided for a patient accurately describes the features visible in the specific 2D slices selected.
- **Feature Sufficiency**: We assume FLAIR modality alone contains enough contrast to distinguish tumor boundaries without requiring T1-weighted or T2-weighted contrast enhancement.
- **Binarization**: We assume a binary task (Tumor vs. Background) is a sufficient starting point for diagnostic validation.

## 8. Limitations
- **2D vs 3D Context**: Processing slices independently loses the volumetric context of the 3D MRI, which can lead to inconsistencies between adjacent slices.
- **Dataset Size**: The current implementation was validated on a subset of 258 slices. Performance may vary when scaled to the full 100,000+ slice BraTS dataset.
- **Report Bias**: The text generation is limited by the vocabulary of the training reports. It may struggle with rare tumor morphologies not well-represented in the Text BraTS corpus.
- **Computational Cost**: The use of a Transformer decoder and a BERT encoder increases inference time compared to a standard, lightweight UNet.

## 9. Conclusion and Future Scope
The project successfully demonstrates that Vision-Language alignment is a powerful tool for medical imaging. Future work should involve **3D VLM-UNet** architectures and **multimodal MRI inputs** (FLAIR, T1ce, T2) to further improve the clinical utility of the generated reports and segmentation masks.
